# ООО «ФИНКА» — лендинг бухгалтерских услуг

Статическая версия сайта: HTML + CSS + JavaScript, без сборщиков и зависимостей.
Редакция: 12.11.2026.

## Состав проекта

```text
finka-site/
├── index.html          — главная страница лендинга
├── privacy.html        — политика конфиденциальности
├── 404.html            — страница ошибки «страница не найдена»
├── robots.txt          — правила индексации для поисковых систем
├── README.md           — этот файл
├── css/
│   ├── base.css        — общее: цвета (токены), шрифты, кнопки, шапка, подвал
│   ├── landing.css     — стили секций главной страницы
│   └── pages.css       — стили «Политики» и страницы 404
└── js/
    ├── nav.js          — шапка, мобильное меню, год в подвале (все страницы)
    └── main.js         — анимации, FAQ, калькулятор, форма заявки (только index.html)
